# Task 2: Customer Churn Prediction

This folder contains the Machine Learning pipeline to predict whether a telecom customer is likely to churn (leave the company). 

### 📌 Task Details:
- **Dataset:** Telco Customer Churn Dataset
- **Models Used:** Random Forest Classifier & XGBoost Classifier
- **Key Techniques:** 
  - Handling Class Imbalance using **SMOTE**.
  - Hyperparameter Tuning using **GridSearchCV**.
  - Feature Importance Analysis.
- **Evaluation Metrics:** Accuracy, Precision, Recall, F1-Score, ROC-AUC Score.
- **Visualizations:** ROC Curve Comparison, Confusion Matrix.
